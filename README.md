# 小鱼糕桌宠 Xiaoyugao Pet

鱼仔与奶盖的小猫鱼，住在 SillyTavern 页面里。她会呼吸、眨眼、冒泡泡、动耳鳍和摆尾巴，也会在你写字、等待回信和切换聊天时陪着你。

**当前版本：1.4.0** · [更新记录](CHANGELOG.md) · [形象替换与二改指南](docs/CUSTOMIZATION.md) · [MIT 许可证](LICENSE)

## 现在会做什么

- **单击摸摸、双击贴贴、长按播报**：长按约 600 ms，可听设备当地时间、今日聊天卡数和今日新增角色回复数。
- **跟随聊天反应**：输入时认真听，生成时陪你等，流式回复时轻轻点头，收到回信后开心迎接；兼容普通生成、流式生成、停止和“扮演我说”。
- **九种动作状态**：`idle`、`listening`、`thinking`、`happy`、`confused`、`petting`、`nuzzling`、`sleeping`、`wave`。
- **趴下与游一游**：待机 12 秒后舒服地趴下；可开启自动游动，也能从设置或公开接口让她游一小段。
- **分层动画**：尾巴与双侧耳鳍按固定锚点旋转，尾根有静态遮盖，不依赖易漂移的逐帧生图。
- **自定义陪伴台词**：按场景每行写一句，支持随机使用、恢复默认，并可给每张单人角色卡设置专属台词。
- **日常／安静模式**：日常主动气泡至少间隔 10 秒、最长显示 5 秒；安静时只回应摸摸、贴贴、长按和设置预览。
- **手机友好**：透明区域不拦点击，气泡会避开屏幕边缘并跟随软键盘位移；支持触摸拖动、位置保存、安全区域和屏幕旋转。
- **大小与性能**：40%–150% 大小、40%–100% 透明度、减少动态效果；聊天页限制绘制帧率，页面在后台时不实际绘制。

## 安装与更新

在 SillyTavern 的扩展面板选择“安装扩展”，粘贴：

```text
https://github.com/phyllis-0612/xiaoyugao-pet
```

安装后刷新酒馆，在 **扩展 → 小鱼糕桌宠** 打开设置。更新时使用扩展管理里的更新按钮，然后刷新页面；当前未启用自动更新。

手动安装时，将完整仓库放进：

```text
SillyTavern/data/<你的用户目录>/extensions/xiaoyugao-pet/
```

请确认 `manifest.json` 直接位于上述目录中，没有多套一层文件夹。

## 日常操作

| 操作 | 小鱼糕的回应 |
| --- | --- |
| 单击／轻点 | 摸摸 |
| 双击／双点 | 闭眼贴贴蹭蹭 |
| 长按约 600 ms | 报时间、今日卡数与今日层数 |
| 拖动 | 换位置，松手保存 |
| Enter／空格 | 键盘摸摸 |
| Shift + Enter／空格 | 键盘播报 |

### 台词变量

| 变量 | 自动填入 |
| --- | --- |
| `{时间}` | 设备当地时间，例如 22:42 |
| `{时段}` | 夜里、早上、上午、中午、下午或晚上 |
| `{角色名}` | 当前单人角色卡名称 |
| `{今日卡数}` | 今天有新回复的角色卡数量 |
| `{今日层数}` | 今天新增的角色回复数量 |

专属台词按角色头像文件名关联；同一张卡的不同聊天共用。群聊使用通用台词。重新导入角色或更改头像文件名后，可能需要重新设置专属台词。

### 今日统计口径

统计从启用功能后开始，不回填历史。只计真实生成中新收到的角色回复；用户消息、系统消息、重生成、续写、候选切换和翻阅旧聊天不会增加。按设备当地日期归零，删除已计入的回复不会倒扣。

## 给其他扩展联动

```js
window.dispatchEvent(new CustomEvent('xiaoyugao:react', {
    detail: { state: 'happy', message: '找到啦！', duration: 1800 },
}));

window.XiaoyugaoPet.nuzzle();
window.XiaoyugaoPet.report();
window.XiaoyugaoPet.swim(1, 2800); // 1 向右，-1 向左
```

还可使用 `status()`、`companionStatus()`、`lieDown()`、`sitUp()` 与 `react()`。

## 主要文件

| 文件 | 负责什么 |
| --- | --- |
| `index.js` | 酒馆事件、手势、拖动、气泡、设置、统计与游动控制 |
| `companion.js` | 台词模板、时间、今日统计和角色专属台词继承 |
| `pet-renderer.js` | Canvas 皮肤、透明分层、姿态和粒子动画 |
| `settings.html` / `style.css` | 扩展设置与界面样式 |
| `assets/` | 小鱼糕形象、姿态与透明图层 |
| `preview.html` | 无需启动酒馆的动作预览页 |
| `tools/` | Node 原生回归测试 |

## 隐私与来源

小鱼糕不会额外调用模型，不增加 token 消耗，也没有遥测或第三方追踪。统计只在本地保存当天所需的角色／聊天标识和回复去重信息，不上传聊天正文。

项目使用 [MIT 许可证](LICENSE)。小鱼糕的形象、台词和水泡动画由鱼仔与奶盖制作；交互控制器在保留自身形象实现的基础上，参考并适配了 [绒信 Rongxin Pet](https://github.com/upcjiangxiaoyi-art/rongxinpet) 的开源实现，版权说明见许可证。
